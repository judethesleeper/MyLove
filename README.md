# MyLove

## Pages

- `index.html`: main romantic homepage
- `photobooth/`: single-device photo booth
- `live-booth/`: two-phone live booth app

## Live Booth Setup

Before `live-booth/` can work, you need to configure Firebase.

1. Create a Firebase project
2. Add a Web App in Firebase
3. Turn on:
   - Firestore Database
4. Copy the Firebase web config into `assets/js/firebase-config.js`
5. Host the site on a secure `https` URL

See [FIREBASE_SETUP.md](/Users/jude/MyLove/FIREBASE_SETUP.md:1) for the full step-by-step guide.
